# Keybinds

| Keybind | Action |
| --- | --- |
| <kbd>Super</kbd> + <kbd>T</kbd> | Open terminal |
| <kbd>Super</kbd> + <kbd>Q</kbd> | Close active window |
| <kbd>Super</kbd> + <kbd>M</kbd> | logout |
| <kbd>Super</kbd> + <kbd>E</kbd> | Open file manager |
| <kbd>Super</kbd> + <kbd>V</kbd> | toggle float |
| <kbd>Super</kbd> + <kbd>D</kbd> | open application menu |
| <kbd>Super</kbd> + <kbd>P</kbd> | toggle pseudo |
| <kbd>Super</kbd> + <kbd>I</kbd> | toggle split |
| <kbd>Super</kbd> + <kbd>F</kbd> | toggle fullscreen |
| <kbd>Super</kbd> + <kbd>&larr;</kbd>, <kbd>Super</kbd> + <kbd>H</kbd> | move focus left |
| <kbd>Super</kbd> + <kbd>&rarr;</kbd>, <kbd>Super</kbd> + <kbd>L</kbd> | move focus right |
| <kbd>Super</kbd> + <kbd>&uarr;</kbd>, <kbd>Super</kbd> + <kbd>K</kbd> | move focus up |
| <kbd>Super</kbd> + <kbd>&darr;</kbd>, <kbd>Super</kbd> + <kbd>J</kbd> | move focus down |
| <kbd>Super</kbd> + <kbd>1</kbd> - <kbd>Super</kbd> + <kbd>0</kbd> | switch to workspace 1-10 |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>1</kbd> - <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>0</kbd> | move active window to workspace 1-10 |
| <kbd>Super</kbd> + <kbd>S</kbd> | open special workspace |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | move active to special workspace |
| <kbd>Super</kbd> + <kbd>Scroll Up</kbd> | move to next workspace |
| <kbd>Super</kbd> + <kbd>Scroll Down</kbd> | move to previous workspace |
| <kbd>Super</kbd> + <kbd>left click</kbd> | move window |
| <kbd>Super</kbd> + <kbd>right click</kbd> | resize window |
| <kbd>Print</kbd> | screenshot region |
| <kbd>Super</kbd> + <kbd>Print</kbd> | screenshot window |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>Print</kbd> | screenshot output |
| <kbd>Super</kbd> + <kbd>`</kbd> | dunst previous notification |
| <kbd>Super</kbd> + <kbd>Shift</kbd> + <kbd>`</kbd> | dunst toggle pause |
